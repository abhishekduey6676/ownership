# Ownership portfolio document

`Ownership-PRD.docx` is generated from [the canonical PRD](../product/PRD.md).
It contains the same content, with readable Word formatting and portable GitHub links.
Do not edit the Word version independently; update the Markdown and rebuild.

Run `python docs/portfolio/build_prd.py` with `python-docx` installed.
The builder checks local source links, source-to-DOCX text parity, repeated table
headers and absence of fixed table row heights. It does not make network calls.

Version 1.0 was structurally checked without visual rendering, at the creator's
request. Pagination and visual layout have not been visually verified. No app
rendering, paid AI calls or runtime behavior changes are part of this document update.

Code references are pinned to the inspected main commit. The newly archived
roadmap links to the documentation branch. The portfolio file does not claim
production AI is enabled or that two-friend feedback proves product-market fit.
